# Teacher guide

This folder is for the mentor. One file per week, plus this page. Mentees get the one-page handouts in `handouts/`.

## The weekly rhythm

The course runs online, with one to three mentees per mentor.

| When | What | Length |
|---|---|---|
| Evening before each session | Send the pre-reading for the next session | 2 minutes |
| Session 1 | First third of the deck, with teach-back | 60 to 120 min |
| Session 2 | Middle of the deck, with teach-back | 60 to 120 min |
| Session 3 | Last teaching part, then start the task live | 60 to 120 min |
| Consolidation | Mentee re-teaches the week; fix gaps | 30 to 45 min |
| Submission day | Task and blog post due | none |

## Teach-back

Each session ends with the mentee explaining the idea back while you play the student. Ask naive questions. If they can't explain it in plain words, they haven't got it yet. Every week's guide lists the prompts.

Link each idea to what the mentee already knows from their own field. Start from first principles, then add the jargon.

## Presenting

- **Local, live class mode:** `npm run teach -- 3` runs week 3. It prints a link for you (speaker view, password protected) and a link for mentees. Their screens follow yours. Add `--online` for a public link mentees can open from anywhere.
- **Hosted site:** mentees open `/week-3/`. You open `/week-3/?key=PRESENTER_KEY#/presenter/1`. Only the view with the key moves the room. Mentees can go back to a slide on their own, and they snap back to you on your next click.
- **Keys in a deck:** P opens presenter view (notes, next slide, timer), O shows all slides, F goes fullscreen, and the arrow keys step through animations.
- The speaker notes hold the teaching script. Read them before each session.

## How to use each week's guide

1. Read "Outcomes" and the session plan before the week starts.
2. Send the pre-reading the evening before each session.
3. Do the task yourself 48 hours before Session 3, on a fresh wallet. Your snags are your class notes.
4. Mark the task and blog post with the two marking tables. Compare against the model answer outline.
5. Use "Common mistakes" to steer teach-back.
6. Short on time? Use "If time is short".

## Blog posts

Mentees publish on dev.to, Medium or Substack. Drafting with AI is fine. The final post must be rewritten in the mentee's own words. Ask them to explain any paragraph out loud. If they can't, it isn't theirs yet.
