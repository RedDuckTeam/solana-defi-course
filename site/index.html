How each week runs

Teach, 30 minutes

Short slides, live diagrams. The detail sits in the speaker notes (press P in a deck for presenter mode).

Do it in class

Two tracks. Users work through wallets, explorers and spreadsheets. Builders do the same plus code.

Write it up

One blog post a week. Six posts by the end is a portfolio for bounties and jobs.

Run it yourself

git clone https://github.com/tobySolutions/solana-defi-course
cd solana-defi-course
npm install
npx slidev week-1.md     # or slides.md for the course map

Press P for presenter mode with notes, O for the slide overview, arrow keys to step through animations. Facts were checked on 11 October 2026; anything that moves weekly carries a date.

Devnet and test tokens only. Never share a recovery phrase. Nothing here is financial advice.
